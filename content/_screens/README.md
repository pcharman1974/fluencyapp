# Story screenshots for picture extraction

Upload the screenshots of each story here: one folder per story, one file per screen, with the
page number first in the file name. Claude then crops each page's picture into the story's
`images/` folder and links it in `story.json`.

Folders: `womens-football`, `inclusive-design`, `once-and-future-queen`, `inventions`, `windrush`,
`carrot-girl`, `home-invasion`. Use `00` for the cover, e.g. `windrush/00.png`, `windrush/01.png`.
Where a page needed two screens, either one will do for the picture.
